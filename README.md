# 周边去哪儿：高德步行推荐

`gaode-nearby` 是一个根据城市、起点坐标和自然语言需求，查询真实地点并核实步行路线的 Agent Skill。版本：1.1.0。

## 功能

- 推荐附近咖啡馆、餐厅、公园等地点，最多提供三个独立备选。
- 各候选路线都从用户给定的同一起点出发，按步行时间、距离和数量条件筛选。
- 根据实际高德工具返回地点详情、步行距离和耗时，不编造地点或路线。
- 对实时营业、安静、门禁及安检等信息保留证据边界；未知条件如实说明。

## 使用方式

仓库根目录的 `SKILL.md` 是完整技能文件，可用于支持 Agent Skills 的工具或作为 ModelScope Skills 的 GitHub 来源。

运行前，Agent 需要配置合法可用的高德MCP地点搜索、地点详情及步行路线工具。仓库不包含API Key；根据所用Agent的配置方式自行设置凭据。

示例请求：

> 城市杭州，起点120.164052,30.254642，找步行15分钟内的咖啡馆，最多3家，优先近一点。

> 城市北京，起点116.374276,39.907379，推荐步行3分钟内的咖啡馆，最多2家。

> 我希望门店安静；如果没有可靠数据，请明确写未核实。

## ModelScope 创建

在 ModelScope Skills 的 GitHub 来源创建入口填写本仓库地址。默认分支为 `main`，Skill文件位于根目录 `SKILL.md`；展示名可填写“周边去哪儿：高德步行推荐”，分类可选择“其他”。以平台实际表单为准。

创建完成后请打开具体Skill页面，确认内容可以查看，再复制该作品的魔搭网址或完整编号。
